# HABduino – kopia dokumentacji

Kopia instrukcji płytki HABduino (tracker RTTY i APRS dla balonów stratosferycznych). Projekt nie jest już rozwijany, a strona habduino.org nie działa. Kopia zachowuje dokumentację dla przyszłych zespołów.

| Plik | Opis |
|---|---|
| `HABDUINO-Instructions.pdf` | Instrukcja HABduino V1.2 (A. Stirk, 2017): zawartość zestawu, wytyczne UKHAS, bezpieczeństwo, uruchomienie, APRS. |
