# Listy kontrolne

Wydrukuj te listy przed misją. Na stanowisku czytaj każdy punkt na głos i zaznaczaj go.

## Role w zespole

| Rola | Zadania |
|-------------------|------------------------------------------------------------|
| Kierownik misji | Decyzja „start/brak startu”. Kontakt z PAŻP. Prowadzi listy kontrolne. |
| Operator tankowania | Butla, reduktor, tankowanie, zamknięcie szyjki. |
| Operator platformy | Gondola, tracker, OBC, odcinacz. |
| Opiekun ładunku | Przygotowanie i włączenie ładunku. |
| Operator śledzenia | Mapy, predykcja, odbiór telemetrii, nawigacja. |
| Kierowca | Pościg, bezpieczna jazda. |

Jedna osoba może mieć kilka ról. Kierowca nie obsługuje śledzenia w czasie jazdy.

## Od 4 do 2 tygodni przed lotem

- [ ] Cel misji i ładunki ustalone.
- [ ] Każdy ładunek dostarczył dane (masa, zasilanie, częstotliwości).
- [ ] Tabela mas wypełniona. Klasa balonu: lekki.
- [ ] Kalkulator: ilość gazu, siła nośna, wysokość pęknięcia.
- [ ] Wstępna predykcja dla kilku terminów i miejsc startu.
- [ ] Ubezpieczenie OC sprawdzone.
- [ ] Operator z licencją krótkofalowca potwierdzony.
- [ ] Zgłoszenie do PAŻP wysłane (termin zasadniczy i zapasowy).
- [ ] Zgoda właściciela terenu startowego.

## 7 dni przed lotem

- [ ] Odpowiedź PAŻP otrzymana. Numer telefonu do służby ruchu lotniczego zapisany.
- [ ] Gaz zamówiony (z zapasem).
- [ ] Materiały jednorazowe kupione (folia, linka, baterie).
- [ ] Subskrypcja SPOT aktywna.
- [ ] Codzienna predykcja.

## 1 dzień przed lotem

- [ ] Tracker skonfigurowany: znak wywoławczy, SSID, payload ID.
- [ ] Tracker widoczny w SondeHub i aprs.fi.
- [ ] Odcinacz sprawdzony na komendę.
- [ ] Baterie naładowane / nowe.
- [ ] Tabliczki: dane kontaktowe, opis, symbole ostrzegawcze.
- [ ] Predykcja: decyzja „start/brak startu”.
- [ ] Sprzęt spakowany według wykazu materiałów.
- [ ] Listy kontrolne wydrukowane.
- [ ] Telefony i powerbanki naładowane.

## Na stanowisku (przed tankowaniem)

- [ ] Pogoda i aktualna predykcja sprawdzone.
- [ ] Podłoże rozłożone: plandeka, koc, folia.
- [ ] Butla zważona / ciśnienie zapisane.
- [ ] Obciążnik przygotowany i zważony (masa = siła nośna szyjki).
- [ ] Elektronika włączona. GPS lock. Telemetria odbierana.
- [ ] Ładunki włączone.

## Start

- [ ] Powłoka zatankowana. Balon unosi obciążnik.
- [ ] Szyjka zamknięta, krętlik przywiązany.
- [ ] Odcinacz uzbrojony. Linka odcinacza zaczepiona.
- [ ] Węzły zabezpieczone taśmą.
- [ ] Gondole zamknięte.
- [ ] Telemetria odbierana (ostatnia kontrola).
- [ ] Brak samolotów w pobliżu.
- [ ] Telefon do służby ruchu lotniczego (jeśli wymagany w zgodzie warunkowej).
- [ ] Start. Czas startu zapisany.

## Lot i pościg

- [ ] Zespół w samochodzie. Jazda w kierunku predykcji.
- [ ] Pozycja i wysokość zapisywane co kilka minut.
- [ ] Odcięcie (jeśli planowane) – komenda wysłana, opadanie potwierdzone.
- [ ] Pęknięcie / odcięcie – czas i wysokość zapisane.
- [ ] Ostatnia pozycja z trackera zapisana.

## Odzyskanie

- [ ] Ładunek odnaleziony.
- [ ] Zgoda właściciela terenu na wejście (pole, las prywatny).
- [ ] Zdjęcia miejsca lądowania.
- [ ] Elektronika wyłączona. Dane z kart SD zabezpieczone.
- [ ] Ładunki przekazane opiekunom.
- [ ] Koniec lotu zgłoszony (jeśli wymagany).
- [ ] Wszystkie osoby i sprzęt w samochodach.

## Po misji

- [ ] Raport z misji napisany w ciągu tygodnia (rozdział „Prowadzenie projektu i dokumentacja”).
- [ ] Wnioski dopisane do rozdziału „Historia i wnioski”.
- [ ] Ta dokumentacja zaktualizowana.
- [ ] Sprzęt sprawdzony, naprawiony i odłożony do szafki z opisem.
- [ ] Rozliczenie kosztów.
